# 음성·번역 공급자

Claude State Bar 설정의 **TTS · STT · 번역 공급자** 칸에서 언어 하나와 기능별 API 공급자를 고릅니다.

| 기능 | 공급자 | 기본값 |
| --- | --- | --- |
| 번역 | Google(Gemini), OpenAI(ChatGPT), Anthropic(Claude) | Google |
| 읽기 | Google, OpenAI | Google, Zephyr |
| 받아쓰기 | Google, OpenAI | Google |

공통 언어는 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 아랍어 순입니다. 설정을 저장하기 전에는 Paseo 화면 언어(한국어/영어)를 따르며, 없으면 한국어입니다.

지금 고른 목소리를 누르면 목록이 펼쳐집니다. 이름을 누르면 고르고 접힙니다. 미리 듣기는 선택을 바꾸지 않고 설정 언어의 고정 문장을 읽습니다. 다시 누르면 멈춥니다. 같은 공급자·목소리·언어의 소리는 설정 화면이 열려 있는 동안 다시 합성하지 않습니다. 칸을 접었다 펴도 유지됩니다. 들리는 소리는 AI가 합성한 음성입니다.

목록은 공급자마다 많이 쓰이는 여성 목소리 6개입니다. Google은 **Zephyr, Aoede, Callirrhoe, Despina, Kore, Leda**(성별은 Google 공식 값), OpenAI는 **marin, alloy, coral, nova, sage, shimmer**(OpenAI는 성별을 공식으로 밝히지 않아 여성 목소리로 통하는 것)입니다. 예전에 저장한 지원 목소리가 이 목록 밖이면 맨 위에 더 보이며 선택을 유지합니다.

한국어로 읽을 때는 숫자를 한국식 말로 바꿔 넘깁니다. 날짜는 `2026-10-10`·`10-10`·`10/10` 모두 "10월 10일", 시각 `15:39`는 "15시 39분", 천 단위 쉼표 숫자 `80,055`는 "팔만 오십오", 범위 `4~5개`·`3-5초`는 "4에서 5개"·"3에서 5초", `1.3x`는 "1.3배", `35ms`·`19MB` 같은 단위는 "35밀리초"·"19메가바이트", `+9`·`-30`은 "플러스 9"·"마이너스 30"으로 읽습니다. 버전 번호(`0.11.4`)·주소 번호·전화번호는 그대로 둡니다. 다른 언어로 읽을 때는 바꾸지 않습니다.

**공급자 설정 저장**을 눌러 언어·공급자·목소리를 적용합니다. 설정은 `~/.paseo/claude-state-bar/speech.json`에 저장됩니다(`PASEO_HOME`이 있으면 그 아래). PC에서 저장하면 받아쓰기 이름 힌트와 같은 서버들에도 보내며 서버별 결과를 보여 줍니다. 서버에서 도는 대화는 그 데몬의 설정과 키를 씁니다.

선택한 공급자가 필요로 하는 키 칸만 보입니다. **키 저장**은 이 기기의 기존 `google.env`에서 비어 있지 않은 칸만 바꾸며 저장한 값은 화면으로 돌려주지 않습니다. Google은 번역·받아쓰기에 `GOOGLE_GEMINI_KEY`, 읽기에 `GOOGLE_TTS_KEY`를 쓰며, OpenAI는 `OPENAI_API_KEY`, Anthropic은 `ANTHROPIC_API_KEY`를 씁니다. 키 확인은 짧은 번역·합성 요청을 보내고 키별 결과를 보여 줍니다. 마이크나 받아쓰기 API 자체를 시험하는 기능은 아닙니다.

번역 보관은 공급자와 언어별로 나뉩니다. 공급자가 없던 옛 항목은 Google 것으로 읽고 원래의 7일 만료를 유지합니다. 키가 없거나 요청이 실패하면 사유를 표시하며 다른 공급자로 넘기지 않습니다.

**생각 상자 자동 번역**(처음엔 꺼짐)을 켜면 번역 단추를 누르지 않아도 대화마다 맨 마지막 생각 상자를 처음부터 번역해 보여 줍니다. 새 생각 상자가 생기면 그 상자로 옮겨 가고, 앞 상자는 이미 받은 번역만 보인 채 더 번역하지 않습니다. 대화를 열거나 모두 펼치기를 눌러도 옛 상자는 번역하지 않으며, 옛 상자는 번역 단추를 눌렀을 때만 번역합니다. 고른 언어로 쓰이지 않은 문단만 번역하고, 번역이 오기 전까지는 원문이 잠깐 보입니다. 켜 둔 동안 맨 마지막 상자의 단추는 원문 보기와 읽기만 남고, 읽기는 번역이 오기를 기다렸다가 번역문으로 읽습니다. 옛 상자의 단추는 꺼져 있을 때와 같습니다. 끄면 단추가 번역·읽기·번역읽기로 돌아가며, 번역읽기는 읽는 동안만 번역을 보여 주고 끝나면 원래 화면으로 돌아갑니다. 서버에서 도는 대화는 그 서버의 키 파일로 번역합니다. 접힌 상자는 번역을 보내지 않고, 펼치는 순간 번역합니다. 입력창 위 모두 접기로 접었든 상자 하나를 접었든 같습니다. 이미 보낸 번역은 접어도 받아 두고, 접힌 상자를 소리로 읽을 때는 번역을 계속합니다. 바로 아래 **생각 상자 자동 펼침**(처음엔 켜짐)은 자동 번역이 켜져 있을 때 지금 생각 중인 상자를 열고 높이 제한을 풀어 스크롤 없이 보이게 합니다.

생각 상자 안에 섞여 들어온 Claude의 말은 Claude Code 대화 기록에서 시작 자리를 찾으면 상자 아래로 옮겨 보여 줍니다. 지금 도는 턴의 상자는 턴이 도는 동안 기록을 이어서 확인하므로(같은 글로 최대 약 10분), 긴 도구 입력을 만드는 동안처럼 기록에 늦게 적힌 말도 밖으로 나옵니다. 턴 중간에 대화를 열었을 때 이미 끝나 있던 상자나 확인을 다 쓴 상자는 턴이 끝날 때 마지막으로 한 번 더 확인하며, 그때까지 말은 상자 안에 남습니다.

모델: Gemini `gemini-3.5-flash-lite`(번역), `gemini-3.8-flash`(받아쓰기), Anthropic `claude-haiku-5-5`(번역), OpenAI `gpt-4.1-mini`(번역·받아쓰기 다듬기), `gpt-4o-mini-tts`(읽기), `gpt-transcribe`(받아쓰기).

목소리 근거: [Google Chirp 3 HD](https://docs.cloud.google.com/text-to-speech/docs/chirp3-hd), [OpenAI TTS](https://developers.openai.com/api/docs/guides/text-to-speech), [OpenAI CLI 합성 예제](https://developers.openai.com/api/reference/cli/resources/audio/subresources/speech/methods/create).

## PC 연결이 끊겼을 때

PC 연결이 끊기면 Calladmin-Gabia가 프로젝트 목록과 관리 화면, 사용량, 설정 화면, 받아쓰기 입력창 보호를 대신 맡습니다. PC가 다시 연결되면 PC로 돌아오며 한 화면에 이 기능들이 한 벌만 보입니다. 다른 서버는 대신 맡지 않고 직원 데몬은 기존대로 동작합니다.

PC 데몬은 시작할 때와 목록·고정·카테고리/프로젝트 순서 파일이 바뀔 때 받아쓰기 이름 힌트와 같은 서버들에 별도 사본을 보냅니다. 사본은 `~/.paseo/claude-state-bar/pc-offline-projects.json`에 저장되며 서버 자신의 목록 파일과 다릅니다. 전달에 실패하면 다음 변경이나 데몬 시작 때 다시 시도합니다. 대체 서버에는 성공적으로 전달된 사본이 있어야 합니다.

Calladmin-Gabia가 대신 맡는 동안 목록·설정은 보기만 가능합니다. PC 프로젝트를 누르면 연결 끊김 안내가 나오고 연결된 서버 프로젝트는 평소대로 열립니다. 사용량과 표시되는 설정 값은 Calladmin-Gabia의 값입니다. 설정·공급자·키·이름 저장, 음원 업로드, 목록 편집과 순서 초기화는 막힙니다. 자동 알림 소리, 기기 사이 설정 맞추기, 화면 배치 저장/가져오기, 대표 기기 지정, 칸 최대화 기록은 PC가 맡습니다. 받아쓰기 입력창 보호는 기존에 지원하던 앱 버전에서만 작동합니다.

## 같은 창에서 Claude 공급자 바꾸기

기기의 Paseo 설정에 Claude 계열 공급자(`claude` 또는 `extends: "claude"`)가 둘 이상 있으면 Claude 대화 입력창 위에 **Claude 공급자** 알약이 붙습니다. 넓은 화면에서는 아이콘 오른쪽에 지금 도는 공급자 이름(Claude (como) 등)이 함께 보이고, 폭이 좁은 화면(폰)에서는 아이콘만 보입니다. 처음 연 공급자와 다르면 주황색입니다. 마우스를 올리면(폰은 창 제목에) **Claude 공급자: Claude (como)**처럼 지금 도는 공급자가 나옵니다. 확인 창은 **X → Y**로 표시하며 Claude, Claude (como), Claude (hrg)처럼 기기의 Paseo 라벨을 그대로 씁니다. 현재 공급자를 제외한 Claude 공급자 중 고르며, 공급자가 둘이면 기존처럼 바꾸기 단추 하나입니다.

바꾸면 해당 Claude가 꺼지고 다음 말에 선택한 계정으로 같은 대화를 이어 떠서 맥락과 화면 기록을 유지합니다. 진행 중인 답은 끊기며 Paseo가 "Claude stopped unexpectedly" 오류를 한 번 띄울 수 있습니다. 확인 창에 이 안내와 현재 맥락 크기가 나오며, 바꾼 뒤 첫 답은 대화 전체를 선택한 계정으로 다시 읽어 그 한도를 씁니다. Paseo에 기록된 공급자와 위쪽 이름은 처음 그대로입니다.

기기별 기록은 `~/.paseo/plugin-data/claude-state-bar/accounts.json`(`PASEO_HOME`이 있으면 그 아래)에 저장되고 보관 시 지워집니다. 공급자 ID로 기록하며 옛 `team`·`personal` 기록도 읽습니다. 두 실행기가 기록을 읽고 감시하여 다른 계정의 `CLAUDE_CONFIG_DIR`·`CLAUDE_CODE_OAUTH_TOKEN`을 지우고 선택한 공급자의 계정 값을 씁니다. 이 값이 없는 공급자는 기본 개인 로그인입니다. PC의 로그인 폴더는 팀 설정 동기화를 먼저 돌리며, 동기화 스크립트가 `CLAUDE_CONFIG_DIR`을 받아야 합니다. 바꿀 모든 공급자는 이 실행기 중 하나를 거쳐야 합니다. 두 실행기는 결국 `claude-rc-relay/relay.mjs` 하나로 돌며(팀 실행기 `claude-team-launch/launch.mjs` 는 그것을 그대로 실행만 함), 명령에는 진짜 Claude 실행 파일을 `--real <경로>` 로 넣어야 합니다. `--real` 이 없거나 값이 비었거나 값이 옵션처럼 보이거나 두 번 나오면 PATH 의 `claude` 를 대신 띄우지 않고 종료 코드 2 와 까닭을 출력하고 멈춥니다. Codex 등 다른 계열로는 못 바꿉니다. 직원 데몬에는 알약이 없고, 직원 데몬이 띄운 Claude 는 바꾸기 기록을 읽지 않으며 자동 전환도 하지 않습니다.

`CLAUDE_CONFIG_DIR`이 있는 Claude 공급자마다 별도 사용량 원천을 등록하고, 괄호를 포함한 Paseo 라벨과 독립된 로그인 갱신을 사용합니다. 그 폴더에 로그인한 뒤 카드가 나타납니다. 1년 `CLAUDE_CODE_OAUTH_TOKEN` 으로만 도는 공급자는 그 토큰으로 사용량을 읽지 못해, 사용량만 읽는 로그인을 따로 둡니다. **Claude 로그인** 칸의 "사용량 보기용" 줄에서 한 번 로그인하면 그 카드도 같은 방법으로 실제 사용량을 읽습니다. 대화는 토큰으로 그대로 돌고, 로그인은 `PASEO_HOME` 아래 `plugin-data/claude-state-bar/usage-login/<공급자>` 에 두며 아무도 읽지 않는 동안에도 만료 직전에 갱신합니다. PC 가 꺼졌을 때도 이 카드를 보려면 PC 대신 화면을 맡는 서버(Calladmin-Gabia)에서 로그인합니다.

공개 플러그인에는 자동 전환 정책이 없습니다. 사용자 전용 실행기 모듈은 지정된 팀 ID `claude-yeogiaen`·`claude-hrg`만 허용하며, 지금 이 공급자 중 하나를 쓰는 대화만 서로 넘깁니다(개인으로 열었다가 손으로 팀으로 옮긴 대화도 포함). 5시간 사용률 85%부터 메인 답이 끝나고 서브에이전트·워크플로우가 모두 끝난 때 넘기며(셸 명령·감시 작업은 기다리지 않음), 실제 5시간 한도 거절 때는 작업을 기다리지 않습니다. 후보마다 짧은 Haiku 요청으로 확인한 가장 낮은 사용률이 쉬는 틈에는 85% 미만, 거절 때는 95% 미만이어야 합니다. 탐침 실패 시 그대로 둡니다. 개인 공급자를 쓰는 대화는 자동 전환하지 않고 개인으로 넘기는 일도 없으며, 팀 둘 다 차면 리셋을 기다립니다. 실행기 환경의 `CLAUDE_TEAM_ROTATION=0`으로 끕니다. Claude Code 2.1.299 이상(2.1.299·2.1.300 확인)의 새 프로세스는 빈 작업 집합으로 시작하며, 그 밖 버전은 전체 작업 목록 이벤트를 받아야 쉬는 틈 전환을 허용합니다. 전환은 다음 말부터 적용되고 멈춘 말은 다시 보내지 않습니다. 자동으로 넘긴 뒤 다음 말 앞에는 꺼진 백그라운드 작업 목록을 알려 Claude 가 다시 걸게 하는 안내가 한 번 붙습니다.

## Claude 다시 로그인

Claude 로그인이 풀려 대화가 "Failed to authenticate"나 "Not logged in" 오류로 멈추면 그 대화 입력창 위에 빨간 열쇠 알약이 붙습니다. 누르면 그 기기 데몬이 `claude auth login`을 대신 띄워 승인 링크를 줍니다. 링크를 폰이나 PC 어느 브라우저에서든 열어 승인하고, 승인 뒤 나오는 코드를 붙여 넣으면 로그인이 끝납니다. 멈춘 말은 다시 보내지 않으며 다음 말을 보내면 대화가 이어집니다. 설정 화면 위쪽 **Claude 로그인** 칸에서도 기기별로 언제든 다시 로그인할 수 있고, 로그인이 풀린 대화가 있으면 이 칸이 펼쳐져 멈춘 대화 수를 보여 줍니다.

로그인 대상은 그 기기 Paseo 설정의 Claude 공급자 중 로그인 파일을 쓰는 것이며, 같은 로그인 폴더(`CLAUDE_CONFIG_DIR`)를 쓰는 공급자는 하나로 묶입니다. env에 `CLAUDE_CODE_OAUTH_TOKEN`을 넣는 공급자는 다시 로그인으로 고칠 수 없어 빠지고, 대신 "사용량 보기용" 줄이 생깁니다. 이 줄에는 로그인한 메일(또는 "로그인 안 됨")이 보여 공급자와 같은 계정으로 승인했는지 확인할 수 있습니다. 공급자를 바꿔 둔 대화는 바꾼 공급자의 로그인 파일에 다시 로그인합니다. 오류는 턴이 끝날 때 마지막 답 글이 이 오류 한 줄인지로 알아봅니다. 로그인 명령이 브라우저를 스스로 열지 않게 하므로 링크는 화면의 **링크 열기**로 엽니다. 로그인 뒤 로그인 파일이 새로 쓰였는지 확인하며, 승인 링크와 코드는 로그에 남기지 않습니다. 팀원 데몬은 관리자가 그 팀원의 Claude 계정을 "본인 로그인"으로 정해 서버에 반영했을 때만 이 칸이 생기며, 팀원이 자기 Claude 계정으로 서버마다 한 번씩 로그인합니다. 로그인 전이나 로그인이 풀렸을 때 회사 공용 계정으로 대신 돌리지 않습니다. "회사 공용" 팀원은 관리자 서버의 토큰을 같이 쓰므로 이 칸이 없습니다.

## 턴 끝난 시각과 직전 내 말로

Claude 답이 끝나면 아래 단추 줄의 작업 시간 뒤에 그 턴이 끝난 시각이 붙습니다(`작업 시간 43s · 오후 2:17`). 시각 모양은 Paseo가 원래 마우스를 올렸을 때 보여 주던 것과 같아서 오늘이면 시각만, 이번 주면 요일, 그 전이면 날짜까지 나옵니다. 시각을 붙인 단추는 마우스를 올리거나 눌러도 글자가 바뀌지 않습니다. 내 말 아래 보낸 시각도 늘 보이며, 되감기·복사 단추는 지금처럼 마우스를 올렸을 때만 나옵니다.

대화마다 입력창 위에 **내말** 알약이 붙습니다(좁은 화면에서는 아이콘만). 누르면 지금 보는 자리 바로 위의 내 말로 가고, 다시 누를 때마다 한 칸씩 더 위의 내 말로 갑니다. 이동은 Paseo 대화 개요(대화 칸 왼쪽 가장자리 눈금)의 이동을 그대로 써서 아직 불러오지 않은 옛 기록까지 갑니다. Paseo 설정에서 대화 개요를 끄면 화면에 그려진 내 말 사이에서만 움직입니다.

Claude가 버튼으로 물은 질문에 답하면 대화의 그 자리에 질문과 고른 답이 카드로 남습니다. 버튼 대신 말로 답했으면 카드에 그렇게 적힙니다. 답을 기다리는 동안은 Paseo 질문 창이 그대로 뜹니다. 다른 대화가 peer_mail로 보낸 글은 대화 안에서 "다른 대화에서 온 글 — 제목" 한 줄로 접히고, 누르면 본문만 펼쳐집니다. 받는 Claude에게는 원래 글이 그대로 전해집니다.

## 세션 가져오기 목록에 바꾼 이름

Paseo에서 대화 탭 이름을 바꾸면 그 대화의 턴이 끝날 때와 보관할 때 같은 이름을 Claude 대화 기록 파일 끝에 Claude `/rename`과 같은 모양의 줄로 적어 둡니다. Paseo의 **세션 가져오기** 목록은 제목을 대화 기록에서만 읽기 때문에(이름 줄, 없으면 Claude가 지은 제목, 없으면 첫 말) 이 줄이 없으면 탭 이름을 바꿔도 목록에는 첫 말(`/start` 같은 것)이 보입니다. Paseo가 첫 말로 붙인 처음 이름과 `/`로 시작하는 이름은 적지 않고, 대화 기록 끝의 이름이 이미 같으면 다시 적지 않습니다. 그 뒤에 다른 이름이 적혔으면 다음 턴 끝에 다시 적습니다. 대화 내용은 건드리지 않고 이름 줄만 덧붙이며 Claude 대화에만 적용됩니다. 팀원 데몬도 똑같이 합니다.

## 따라 읽기

대화마다 입력창 위에 헤드폰 알약이 붙습니다. 누르면 그 대화의 Claude 말을 지금부터 문단이 끝나는 대로 이어서 소리로 읽고, 켜진 동안 아이콘이 녹색입니다. Claude 말 안의 글을 선택해 두고 켜면 그 문단부터 뒤의 말을 모두 이어 읽습니다. 선택이 없으면 Claude가 말하는 중에 켤 때 그 말 처음부터, 생각하거나 도구를 돌리거나 쉬는 중에 켤 때 다음 말부터 읽습니다. 끌 때까지 다음 턴도 계속 읽으며, 알약을 다시 누르거나 입력창 위 읽기 조절의 중지를 누르면 꺼집니다. Claude 말 아래 스피커를 누르면 따라 읽기를 할지 먼저 묻습니다. 턴 끝 줄의 스피커, 말마다 붙은 스피커, 생각 상자에서 꺼낸 말 아래 스피커가 모두 그렇고, 생각 상자 자체의 읽기 단추는 묻지 않습니다. 확인하면 그 턴이나 말의 처음부터 읽고 이어서 새로 오는 말도 계속 읽으며, 취소하면 그 턴이나 말만 읽습니다. 이미 따라 읽는 대화나 읽는 중에 다시 눌러 멈출 때는 묻지 않습니다. 따라 읽기는 대화마다 따로 켜집니다. 다른 대화의 알약을 눌러도 이 대화의 따라 읽기는 꺼지지 않고, 같은 대화에서 다른 읽기 단추를 누를 때만 그 읽기로 넘어갑니다. 따라 읽는 대화를 떠나 다른 대화로 가면 읽던 문단만 끝까지 읽고 기다렸다가, 돌아오면 이어 읽습니다. 그래서 두 대화의 소리가 잠깐 겹칠 수 있습니다(폰 앱은 소리를 하나만 틀 수 있어 나중에 시작한 쪽이 앞 소리를 끊고, 끊긴 대화는 돌아오면 이어 읽습니다). 입력창 위 읽기 조절은 지금 보고 있는 대화의 따라 읽기를 조절하고, 그 대화에 따라 읽기가 없으면 다른 읽기를 조절합니다. 읽기 속도는 모든 읽기가 같이 씁니다. 페이지를 새로 고치면 꺼집니다. 다른 탭으로 가 있거나 창을 최소화해 Paseo 화면이 숨은 동안에도 새 문단을 계속 모아 넘깁니다. 생각 상자 본문은 읽지 않고 상자에서 꺼낸 말은 읽습니다. 다른 읽기처럼 화면에 보이는 글을 읽으며, 소리 읽기를 쓸 수 있을 때(음성 합성 키가 있고 설정에서 소리 읽기가 켜져 있을 때)만 알약이 보입니다. 따라 읽기는 앞으로만 읽습니다. 이미 읽으려고 넘긴 말보다 화면 위쪽에 늦게 생긴 말, 예를 들어 기록이 늦게 적혀 나중에 옛 생각 상자에서 꺼낸 말이나 켤 때 출발점보다 위에 있던 상자에서 꺼낸 말은 자동으로 읽지 않습니다. 그런 말은 화면에 남아 이 말 읽기 단추로 따로 읽을 수 있고, Claude가 일하는 중에 맨 끝 상자에서 꺼낸 말은 다음 말로 읽습니다.

폰 앱에서는 무엇이든 소리로 읽는 동안 유튜브 같은 다른 앱 소리를 원래의 20%로 낮추고, 읽기가 멈추거나 다음 문단을 기다리면 되돌립니다. 소리 설정의 **읽기 중 다른 소리 줄이기**에서 끌 수 있고 처음엔 켜져 있습니다. PC는 지원하지 않습니다.

## 단축키·프로젝트 메뉴·압축 준비 소리

웹과 PC 앱에서 **Ctrl+Alt+Shift+F**는 대화 칸 최대화를 켜고 끕니다. 최대화된 칸이 있으면 풀고, 없으면 입력 커서가 든 칸, 화면에 보이는 대화 칸, 첫 칸 순서로 골라 최대화합니다. 작업 현황 칸은 이 키로 최대화하지 않습니다. **Ctrl+Alt+Shift+W**는 지금 작업 공간의 작업 현황을 엽니다. 이 플러그인의 단축키(왼쪽 칸 전환·칸 최대화·작업 현황·읽기 속도)는 설정 화면의 **단축키** 칸에 모여 있고 거기서 바꿀 수 있습니다. 입력창 목록 키(Shift+Enter·Tab·Backspace)는 바꿀 수 없고 다른 단축키로도 고를 수 없습니다. [바꾸기]를 누른 뒤 쓸 키를 누르면 기록되고 [저장]으로 적용되며, 모든 화면이 같은 키를 씁니다. 플러그인 단축키끼리 같은 키는 저장되지 않고, Paseo 단축키와 겹치면 경고만 보입니다. 위에 적은 키는 처음 값입니다.

말이나 생각 상자를 소리로 읽는 동안 **Ctrl+←**는 읽기 속도를 한 칸 늦추고 **Ctrl+→**는 한 칸 높입니다. 읽는 중에만 이 키를 가로채므로 그동안은 입력창에서 이 키로 단어 단위 커서 이동이 되지 않습니다. 한글을 조합하는 중이면 무시합니다.

왼쪽 프로젝트 목록은 앱을 열거나 새로 고치면 활성 묶음만 펼치고 고정·카테고리·숨김 묶음은 접힌 채로 시작합니다. 활성 묶음 줄 오른쪽에는 그 프로젝트에 Claude가 질문을 올려 답을 기다리는 대화가 있으면 물음표가, 압축 명령어를 넣을 차례인 대화가 있으면 안으로 모이는 화살표가 주황색으로 붙습니다. 왼쪽 프로젝트 목록에서 프로젝트를 오른쪽 클릭하면(폰은 길게 누르기) **이름 복사**와 **이름 바꾸기**가 뜹니다. 이름 바꾸기는 관리 화면의 것과 같고 Enter로 저장, Esc로 취소합니다. PC가 꺼져 서버가 대신 보여 주는 동안과 직원 화면에서는 이름 복사만 나옵니다. 이미 프로젝트가 있는 디바이스·경로로 또 추가하면, 처음 것이 메인으로 남고 새 것은 그 저장소의 git 워크트리가 됩니다. 관리 화면이 그 디바이스의 Paseo에 워크트리 작업 공간을 만들어 달라고 하면 Paseo가 늘 쓰는 워크트리 자리에 만들고, 이름은 메인 이름 뒤에 비어 있는 가장 작은 번호를 붙이며(Mesa → Mesa1, Mesa2), 경로는 그 워크트리 폴더가 됩니다. 워크트리마다 폴더가 따로라 대화, 고정, 끌어 놓은 순서, 숫자가 메인과 따로 움직입니다. git 저장소가 아닌 폴더는 프로젝트를 하나만 둘 수 있습니다. 워크트리 프로젝트를 지우면 목록에서만 빠지고, 워크트리 폴더와 브랜치는 직접 합치고 정리할 때까지 남습니다.

사용량 칸의 카드는 개인 Claude, 팀 Claude 공급자, 그 밖의 공급자(Codex 등) 순서로 놓입니다. 팀 카드끼리는 플러그인에 적어 둔 순서를 따르고, 그 목록에 없는 공급자는 뒤에 이름순으로 붙습니다. 카드 제목에는 메일을 붙이지 않고(`Claude`, `Codex`), 메일을 떼고 나서 같은 이름이 둘 이상이면 그 카드들만 메일을 남깁니다. 제목 옆 괄호 숫자(`(5)`)는 그 계정을 쓰는 열린(보관 안 된) 대화가 있는 프로젝트 수이며, 화면에 연결된 기기를 모두 합쳐 셉니다. 웹과 PC 앱에서는 숫자에 마우스를 올리면 프로젝트 이름(폰·PC 알림 제목과 같은 `이름 - 카테고리`)이 뜨고, 누르면(폰은 탭) 다시 누를 때까지 남습니다. 그 계정을 쓰는 대화가 없으면 흐린 (0) 으로 보입니다. Fable 주간 막대는 접혀 있고, 카드를 누르면(폰은 탭) 다시 누를 때까지 펼쳐 둡니다. 마우스를 올리는 것만으로는 펼치지 않습니다. 모든 카드의 막대는 같은 자리에서 같은 길이로 그려지고, 끝나는 시각은 늘 날짜와 함께(`10/16 00:29`) 보입니다. Paseo 는 받아 온 사용량을 5분 동안 기억하며, 펼친 칸의 접기 화살표 옆 갱신 아이콘을 누르면 모든 카드를 그 자리에서 다시 받습니다. 개인 Claude 로그인은 만료되기 전에 미리 갱신해, 그 계정을 쓰는 대화가 없어도 개인 카드가 보입니다.

팀 공급자 카드와 Paseo 기본 Claude 카드가 같은 계정·조직이면 사용량 칸에는 팀 카드 한 장만 보이고, 팀 공급자 둘이 같은 계정이면 Paseo 설정의 공급자 순서상 첫 카드만 보입니다. 같은 계정인지는 메일이 아니라 로그인마다 Anthropic 이 알려 주는 계정·조직 번호로 판단합니다. 팀 카드가 사용량을 못 읽으면 팀 카드는 빠지고 그 자리에 기본 카드가 보입니다. 이 Paseo 판에서 원본 보고를 읽지 못하면 두 장이 그대로 보이고, 그 까닭은 설정 화면의 **기능 상태** 칸에 나옵니다.

다른 탭으로 가 있거나 창을 최소화해 Paseo 화면이 가려진 동안에는 작업 현황, 프로젝트 숫자, Codex 목록이 새로 고치기를 멈추고, 화면이 다시 보이면 바로 새로 고칩니다. 작업 자체는 그대로 돌고 소리도 그대로 납니다.

폭이 좁은 화면(폰)에서는 사용량·작업 현황이 머리줄 단추가 아니라 입력창 위 알약으로 붙어, 머리줄의 세로 점 메뉴에 더는 들어가지 않습니다. 컨텍스트·작업 현황·사용량 세 알약은 다른 알약 아래 둘째 줄에 놓이고, 읽기 조절은 그 줄의 남는 공간 가운데에 작게 뜹니다. 그 프로젝트에서 하위 에이전트·백그라운드 작업·Codex 실행이 돌고 있으면 알약 줄 위 왼쪽에 (1, 0, 3)처럼 개수가 작게 나오고, 셋 다 0 이면 개수는 나오지 않습니다. 폰에서는 공급자 알약이 아이콘만 보이므로, 그 대화가 지금 도는 Claude 공급자 이름이 개수 뒤에 붙습니다((1, 0, 3) · Team처럼, 개수가 없으면 이름만). 공급자를 바꾸면 이름도 따라 바뀌고, 공급자 알약이 없는 대화(Codex 등)는 개수만 나옵니다. 폰 앱에서는 입력창 위 알약, 입력창 둘레 단추(받아쓰기 취소·넣기·넣고 보내기, 첨부, 모델 선택, 보내기 등), 프로젝트 목록에서 프로젝트를 고를 때 짧게 진동합니다. 이 기능을 지원하는 폰 앱 판이어야 하고, 폰의 터치 진동 설정을 따르며, 설정 화면의 "누를 때 진동"으로 끌 수 있습니다. 넓은 화면에서는 사용량·작업 현황 머리줄 단추가 그대로 있고 이 두 알약은 없습니다. Claude State Bar 설정 톱니는 어느 화면에서나 입력창 위 알약 줄 맨 오른쪽에 있고, 누르면 바로 설정 화면이 열립니다. 웹의 대표 배치 가져오기는 따로 머리줄 단추로 있습니다(폰에는 없습니다).

폭이 좁은 화면(폰)에서는 입력창 위의 변경 줄 수 알약(`+38.7k -0`)을 숨겨 다른 알약 자리를 넓힙니다. 넓은 화면에서는 그대로 보입니다. 소리 크기는 50~1000%까지 정할 수 있고, 300%를 넘기면 원래 큰 소리는 찌그러질 수 있습니다.

Claude 답의 마지막 글에 `/compact 세션로그 … 가 이 세션의 정본이다`로 시작하는 줄이 있으면 끝남 소리 대신 **압축 준비** 소리를 냅니다. 압축 전 체크포인트(`start_compact`)가 끝나 압축 명령어를 복사할 차례를 다른 일을 하다가도 알아차리게 하려는 것입니다. 처음 값은 Windows 캘린더 알림(macOS는 Submarine)이고 설정 화면의 소리 칸에서 바꿉니다.

## 폰 푸시

Paseo 웹을 감싼 Android 앱(`com.blueming.paseo`)에서는 손을 써야 하는 일 두 가지를 폰 알림으로도 받습니다. Claude가 버튼으로 질문하거나 계획 승인이나 도구 사용 허락("매번 묻기" 같은 모드에서 Paseo가 띄우는 허락 창)을 기다릴 때와, 압축 전 체크포인트가 끝나 압축 명령어를 넣을 차례일 때입니다. 도구 사용 허락은 PC에서도 질문 소리로 울리고, 알림에는 도구 이름과 설명만 실리며 명령 원문은 싣지 않습니다. 지금 보고 있는 대화가 아니어도 모든 대화가 보냅니다. 폰 앱이 알림을 받았다고 3초 안에 답하면 그 질문·압축 준비 소리는 PC에서 울리지 않고, 폰이 PC 설정에서 고른 같은 소리로 울립니다. 폰 앱이 꺼져 있어 답이 없으면 PC에서도 울립니다. 질문에 답하면(PC에서 답해도) 알림이 지워지고, 압축 준비 알림은 그 대화에 다음 말이 시작되거나 대화를 보관하면 지워집니다. 알림 제목은 "질문 — 프로젝트 이름 - 카테고리"처럼 작업 공간 제목("카테고리 - 이름")을 뒤집어 붙이므로, 제목이 길어 끝이 잘려도 어느 프로젝트인지 먼저 보입니다. Paseo가 PC 화면 구석에 띄우는 알림("Agent finished" 등)에도 같은 이름을 끝에 붙입니다(데스크톱 앱이 바꾸기를 막아 둔 창은 그대로입니다). 알림을 누르면 그 대화가 열립니다. 기기마다 데몬이 자기 대화의 알림을 Firebase로 직접 보내므로 각 기기의 `~/.paseo/claude-state-bar/fcm-service-account.json`에 서비스 계정 키가 있어야 합니다. 키가 없는 기기와 직원 데몬은 보내지 않습니다.

알림을 어떻게 보낼지는 기기마다 `~/.paseo/claude-state-bar/push-central.json`(`PASEO_HOME`이 있으면 그 아래)에서 고릅니다. 이 파일이 없으면 위에 적은 대로 데몬이 Firebase로 직접 보냅니다(`legacy`). `"mode": "central"`과 https 주소·기기 번호·비밀을 담은 `central` 칸을 넣으면 데몬은 알림을 중앙 게이트에 넘기고, Firebase 키는 게이트만 가지며 폰은 게이트가 허락한 뒤에만 울립니다. 게이트에 닿지 못해도 직접 보내기로 되돌아가지 않고 PC만 울립니다. 이 방식에서 PC는 게이트의 판정을 최대 15초만 기다렸다가 스스로 울리고, 그 뒤에 온 폰 허락은 거절되므로 두 곳이 함께 울리지 않습니다. 차례 번호가 없는 압축 준비 알림은 이 방식에서 PC에만 남습니다. `"mode": "off"`는 폰 알림을 보내지 않습니다. 파일이 있는데 읽을 수 없거나, JSON이 깨졌거나, 다른 방식 이름이 적혔거나, `central` 칸이 없거나 틀리면 그 기기의 폰 알림이 꺼지고 데몬 기록에 까닭이 남습니다. 파일을 고치면 데몬을 다시 띄우지 않아도 다음 알림부터 적용됩니다.

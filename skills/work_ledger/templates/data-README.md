# 작업 장부 데이터

work-ledger 가 쓰는 장부입니다. 사람과 AI(Claude·Codex 등)가 같은 장부를 읽고 씁니다.
도구가 없어도 이 파일들은 그냥 읽을 수 있게 만들었습니다.

## 구조

```
projects/<프로젝트>/items/<만든 날>-<4자>.md   할 일 하나 = 파일 하나
```

파일 모양:

```markdown
# 할 일 제목
<!-- work-ledger item 2026-10-26-a7k2 · 아래 기록은 덧붙이기만 한다 -->

## 기록
- 2026-10-26 04:01:22 · 리규형님 · 할 일 · 메모
- 2026-10-26 04:05:10 · Claude · 진행 중 · 무엇을 하는지
- 2026-10-26 06:10:44 · Codex · 끝냄 · 무엇으로 확인했는지
- 2026-10-26 09:00:03 · 리규형님 · 확인됨 ·
```

- 한 줄 = `시각 · 누가 · 무엇 · 내용`. 시각은 한국 시각입니다
- **현재 상태 = 시각순으로 마지막 상태 줄**
- 상태: 제안 · 할 일 · 진행 중 · 끝냄(확인 대기) · 확인됨 · 보류 · 버림. 그 밖에 메모 · 제목(제목 바꿈)

## 규칙

- **줄을 지우거나 고치지 않습니다. 덧붙이기만 합니다.** 그래서 여러 기계가 동시에 써도
  `.gitattributes` 의 `merge=union` 으로 줄이 합쳐지고, 지난 기록이 사라지지 않습니다
- "끝냄"은 AI 가 무엇으로 확인했는지 근거와 함께 찍습니다. "확인됨"은 사람만 찍습니다
- `_site/` 는 보기 화면(HTML)이라 git 에 넣지 않습니다. `ledger html` 로 언제든 다시 만듭니다

## 1. 작업 흐름

### 1-1. 아침 7:31 알림의 정체

**배경/요구**: 사용자가 텔레그램 스크린샷 2건을 보내며 "이건 뭔 개같은 알림이지?".

**처리**: `diag.log` 타임스탬프와 대조. `22:31:23Z` = **07:31 KST** 로 정확히 일치했다.

```
22:31:23.900Z codex-poll moved=-1000ms isOpen=N wasOpen=Y  ← CLOSE EDGE
22:31:25.001Z codex-primer-outcome=api-key-present
              detail=could not read \root\.codex\auth.json (ENOENT)
```

**결과**: 두 알림 모두 **옛 코드가 낸 거짓 알림**. 재로드(07:40경) 직전이었다.
알림 문구가 "ChatGPT 플랜으로 로그인되어 있지 않아 API 크레딧으로 과금됩니다" 인데,
실제로는 로그인이 멀쩡했고(`auth_mode="chatgpt"` 확인) 프라이머는 **거부하고 끝났으므로
과금도 일어나지 않았다.** 파일을 못 찾은 것을 "로그인 없음"으로 단정한 문구다.

### 1-2. 경로 공백 제거 (사용자 작업)

**배경/요구**: `codex_rescue` 스킬이 경로의 공백 때문에 작동하지 않았다.

**처리**: 사용자가 `Etc Project` → `EtcProject`, `VsCode Extentions` → `VsCodeExtentions` 로
변경. `~/.claude/projects/` 아래 프로젝트 폴더명(`f--workspace-…`)도 함께 바뀌어
**메모리와 대화 기록을 수동으로 복구**했다.

### 1-3. 🔴 수정본 실전 검증 — 진동이 하필 두 번 왔다

**배경/요구**: 코덱스 창이 10:56에 닫힐 예정이라 사용자가 "이때 어떻게 발사하는지 보면 되겠지?".

**처리**: 종료 전후 폴링을 그대로 관찰했다.

```
01:53:02Z (10:53)  moved=1000ms    isOpen=Y wasOpen=Y            ← 진동, 걸러짐
01:55:02Z (10:55)  moved=-1000ms   isOpen=Y wasOpen=Y            ← 진동, 걸러짐
01:57:02Z (10:57)  moved=18049000ms isOpen=N closedFor=0m  ← CLOSE EDGE
01:57:02Z          codex-block-closed event=2979659 autoStart=true
01:57:10Z          codex-primer-outcome=fired  tail: ok
01:57:42Z          codex-primer-verified resetsAt=…T06:57:09Z (fixed → window open)
```

**결과**: 전부 통과.
- **진동 2회가 실제로 발생**했고 둘 다 열림으로 판정됐다. 구코드였다면 거짓 알림 2건
- 진짜 종료(5시간)는 정확히 잡았고 **락은 `event-codex-2979659` 하나만** 생성
- 프라이머가 로컬 경로를 보고 성공 — `\root\.codex` ENOENT 재발 없음
- 검증까지 통과 → 새 창 **15:57까지**, 사용률 0% → 1%
- `closedFor=0m` 표시가 붙은 것 자체가 **신코드가 도는 증거**다

> "텔레그램 한번왔고, 리셋도 된듯" — 사용자

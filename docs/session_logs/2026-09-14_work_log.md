## 4. 발견한 코드베이스 함정

### `npm run package` 스크립트가 전역 `vsce`에 의존하는데 이 PC에 없다
`package.json`의 `"package": "vsce package"`는 전역 설치된 `vsce` CLI를 찾는다. 이 PC(BluemingPC)에는
전역 vsce가 없다(`npm ls -g`에 없음, PATH에도 없음). 있는 것은 `npx`가 캐시해 둔
`~/AppData/Local/npm-cache/_npx/28f98e99224dac41/node_modules/vsce`뿐이다. 그래서
`npm run package`를 실행하면 즉시 "명령을 찾을 수 없음"(한글 로캘이라 한글로 출력, 종료 코드 1)으로
죽는데, **직전에 만들어 둔 `.vsix`가 작업 폴더에 그대로 남아 있어서** 그 뒤에 오는
`code --install-extension claude-state-bar-1.15.0.vsix --force`는 **그 옛 파일을 다시 설치**하고
"성공"을 출력한다. 버전 번호가 바뀌지 않는 패치 작업(문서 수정, 소폭 기능 추가) 중에는 파일명도
그대로라 겉보기로 전혀 구분이 안 된다.

올바른 명령은 `npx --yes @vscode/vsce package`. 설치 전 반드시 `.vsix`의 mtime이 방금인지,
안의 내용(문자열 검색)이 이번 변경을 반영하는지 확인해야 한다. [[feedback_build_install]]에
이 사고를 반영해 갱신함.

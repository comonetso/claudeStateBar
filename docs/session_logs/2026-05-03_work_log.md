## 1. 작업 흐름 (시간순)

### 1-1. v1.5.0 신기능 구현 (이전 세션에서 완료된 상태)
**요구사항**:
1. 상태바 클릭 → QuickPick 컨텍스트 메뉴 (hide/restore/settings)
2. 현재 사용 모델 표시
3. idle 세션 숨기지 않고 회색조(dimmed)로 표시
4. effort 레벨 표시 (`~/.claude/settings.json`의 `effortLevel` 필드)
5. 표시 형식: `{name}: {Model} - {Effort} ({pct}%)`
6. 배경색 제거 → 글자색 경고 (노란/빨강 배경 너무 거슬림)
7. Opus 4.x = 1M context 자동 감지
8. 워크스페이스 자동 매칭 (scope='workspace' 기본값)
9. contextLimit → contextLimitDefault / contextLimitOpus 분리
10. warningThreshold order:1, dangerThreshold order:2

**결과**: 컴파일 통과, .vsix 패키징 완료

### 1-2. 리눅스 미표시 버그 진단 (v1.5.1)
**배경**: 사용자가 리눅스 서버에서 익스텐션이 안 보인다고 보고. 원래 v1.4.1에서는 정상 동작했음.
**원인 탐색**:
- Output Channel 없어서 진단 불가 → Output Channel 추가
- `Show Diagnostics` 커맨드 추가 후 로그 확인
- 1차 발견: `_` → `-` 인코딩 누락 (`sported_new` → `sported_new` vs Claude의 `sported-new`)
- 2차 확인: `.` → `-` 인코딩도 누락 (`.claude` → `--claude` 패턴에서 확인)
- 3차 발견: `hideAfter` 기본값 1시간인데 모든 세션이 16시간+ 이상 → 전부 필터링

**수정 내용**:
- `encodeWorkspacePath`: `[:\\/\s]` → `[:\\/\s_.]` (언더스코어, 점 추가)
- `--claude` 접미사 디렉토리 명시적 스킵 추가
- `projectDirMatchesFolder` 함수 추가 (3단계 폴백 매칭)
- `hideAfter` 기본값: 3600 → 86400 (1시간 → 24시간)
- `hideAfter` 최대값: 86400 → 604800 (7일)

## 3. 시행착오

- **priority 값 반복 조정**: 900+ (너무 왼쪽) → -10000 (너무 오른쪽) → -100 → 500 → 10 (편집기 옵션 오른쪽에 위치)
- **IDE diagnostics 오탐**: 컴파일은 통과했는데 IDE가 이전 상태를 보고. grep으로 실제 파일 확인해서 정상 확인
- **`_` 인코딩 누락**: 처음엔 경로 인코딩이 맞을 거라 가정했는데 실제 로그 찍어보니 `sported_new` vs `sported-new` 불일치 발견

## 4. 코드베이스 함정

- Claude Code는 경로 인코딩 시 `/`, `\`, `:`, `_`, `.`, 공백 → 전부 `-` 로 치환
- `--claude` 더블 대시는 `/path/.claude`에서 `/` + `.` 둘 다 `-`가 되면서 발생
- `effortLevel` 필드는 JSONL에 없고 `~/.claude/settings.json` 글로벌에만 존재
- `hideAfter` 기본값이 너무 짧으면 리눅스 서버처럼 간헐적 사용 환경에서 세션이 전부 숨겨짐
- `scope='workspace'`에서 `workspaceFolders`가 null이면 필터링 자체를 스킵 (전체 표시)

## 1. 작업 흐름
### 1-1. Sonnet 5/4.6 컨텍스트 한도 버그
**배경/요구**: 사용자가 "소넷 모델 Context Window가 기본 1M으로 바뀌었다"고 제보, 기본값 반영 요청.
**처리**: claude-api 스킬로 확인한 결과 `claude-sonnet-5`, `claude-sonnet-4-6`은 1M이 기본(Sonnet 4.5 이하만 200K 유지). [extension.ts:1786](../../src/extension.ts#L1786) `getContextLimitForModel()`에 Sonnet 메이저 버전 분기(≥5 또는 4.6+) 추가, `mythos` 패밀리도 fable과 동일하게 1M 인식 추가.
**결과**: 컴파일 통과, v1.7.30 패키징 후 로컬 설치 완료.

## 4. 발견한 코드베이스 함정
- **Sonnet 버전 정규식의 날짜 접미사 오매칭 함정**: 구버전 dated 모델 ID(예: `claude-sonnet-4-20250514`)는 `sonnet-4` 뒤에 마이너 버전 없이 바로 8자리 날짜가 붙는다. 단순히 `sonnet-(\d+)-(\d+)` 식으로 매칭하면 날짜 앞 2자리(`20`)를 마이너 버전으로 오인해 1M으로 잘못 판정할 위험이 있음. `(?!\d)` 부정 전방탐색으로 "뒤에 또 숫자가 오면 그건 날짜니까 마이너 버전이 아니다"를 걸러야 함. (`getContextLimitForModel` 참고, [extension.ts:1786](../../src/extension.ts#L1786))

## 4. 발견한 코드베이스 함정 ★

- **★ template literal 안 이스케이프 함정**: `getHtml`이 백틱 template literal로 webview HTML/JS를 만든다. 그 안의 JS 문자열에 `\n`·`\t`를 쓰면 **컴파일 시 실제 제어문자로 변환**되어 webview JS가 깨진다. **정규식도 동일** — `/\{(\d+)\}/g`는 `\{`·`\d`가 먹혀 `/{(d+)}/g`로 깨진다. 반드시 **이중 백슬래시**(`'\\n'`, `/\\{(\\d+)\\}/g`). 컴파일은 통과하고 런타임 webview에서만 터져 더 위험.
- **모달 버튼 반환값 비교**: `showWarningMessage(msg, '삭제')` 후 `if (answer !== '삭제')`. i18n 시 버튼 텍스트와 비교 문자열이 같은 `planT()` 결과를 봐야 함 → **변수로 묶어야** "항상 취소" 버그 방지.
- **카드 제목 데이터 레이어 한글 생성**: 워크플로우 카드 name(`서브에이전트 hh:mm (N마리)`)이 extension.ts에서 생성돼 webview로 전달됨 → webview dict 주입만으론 i18n 안 됨. `planT()`로 생성 지점 처리 필요.
- **deriveAgentRoleLabels 50자 컷**: 라벨이 50자 초과 시 `slice(0,50)+…`. 전체를 보려면 잘리기 전 원본을 별도 보존해야(fullName).
- (직전 세션 박제 재확인) **agent-*.jsonl은 완성 메시지 단위 append** — 토론류(도구無)는 단계 1개. collectAgentSteps도 이 한계 그대로.

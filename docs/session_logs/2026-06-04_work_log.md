### 1-3. ★ 어드버서리얼 검증 4렌즈 → 치명 버그 2개 발견
**처리**: "5마리가 전부 정상"이라 보고했으나 독립 검증 4렌즈(Workflow 도구)를 추가로 돌림.
**발견된 버그**:
1. **[치명] done 판정 무음**: `parseTaskAgent`가 `stop_reason === 'end_turn'`만 done으로 봤는데, 실제 로그에 완료된 에이전트의 `stop_reason`이 `null`인 케이스가 있음 (실측: 3개 중 2개가 null + 완결 보고). → 영구 running 판정 → 비프 영구 무음.
2. **[치명] false-done 조기 비프**: `textBlock && !toolUseBlock && sr!=='tool_use'` 조건이 진행 중 "중간 설명 텍스트"(tool_use 앞에 별도 라인으로 flash됨, sr=null)도 done으로 오판 → 조기 비프 + 게이트 set → 진짜 완료 시 비프 누락.
   - 실측: 중간 텍스트 최대 634자, 최종 보고 최소 3169자 — **겹침 없음**이 핵심 단서
**수정**: `end_turn`이면 즉시 done. `null`이면 `≥1500자(최종보고) + 4초 settle`일 때만 done.
**검증**: 14개 에이전트 파일 Python 실측 — old: 1/3 done → new: 3/3 done, false-done 0건.

## 4. 발견한 코드베이스 함정

### 4-1. ★ Claude Code 최신 버전 agent jsonl: stop_reason=null이 완료일 수 있음
- Task 에이전트 로그 `agent-*.jsonl`의 마지막 assistant 엔트리 `stop_reason`이 `null`이어도 완료일 수 있음.
- 실측: 이 세션 Task 에이전트 3개 중 2개가 sr=null + 완결 보고서(3169자+).
- 구분법: `end_turn` → 즉시 done. `null` → **≥1500자 + 4초 settle** 조합만 done. `≤634자`(중간 설명)는 항상 running.
- 파일: `parseTaskAgent` done 판정부 (`src/extension.ts`, 1186행 근처 주석 참조)

### 4-2. ★ Claude Code 에이전트 중간 텍스트 flush 패턴 (false-done 유발)
- Claude Code가 tool_use 직전에 설명 텍스트를 **별도 엔트리로 먼저 flush**함. 그 찰나(0.6초 중앙값, 최대 25초)에 폴링되면 text-only+sr=null이 마지막 엔트리 → done 오판.
- 파일워처가 그 append 순간을 트리거하므로 거의 항상 이 창에 걸림.
- 실측: 14개 에이전트, 181개 중간 엔트리, 중앙값 0.6초.

### 4-3. workflowPanel.ts webview 스크립트 NUL 바이트 — 컴파일 통과
- 에이전트가 코드 작성 중 U+0000을 주석에 삽입해도 tsc는 통과함. 하지만 Electron webview html에 그대로 주입되어 엄격 파서/CSP 리스크.
- 탐지: PowerShell `[char]0` grep 또는 hexdump로만 발견 가능. `grep` 바이너리 취급으로 놓칠 수 있음.

### 4-4. ultracode 저장 메커니즘 — 확장 번들 디컴파일로 확정
- `writeUserSettingsAndPush(channelId, settings, flagsOnly)`: `flagsOnly=false` → settings.json 디스크 영속. `flagsOnly=true` → 런타임만.
- `effortLevel` = flagsOnly 없음 → **영속**. `ultracode:true` = flagsOnly:true → **런타임 전용**.
- 결과: 디스크엔 `effortLevel:"xhigh"`만 남아 순수 xhigh와 ultracode 구분 불가 → `xHigh⁺` 근사 표시가 최선.
- 관련 파일: `~/.vscode/extensions/anthropic.claude-code-2.1.161-.../extension.js`

### 4-5. extensionKind:["ui"] — 로컬 설치 1회 = 모든 Remote-SSH 창 자동 적용
- ui 확장은 로컬(클라이언트)에서만 실행되므로 원격 재설치 불필요.
- 이를 사전에 고지 않아 사용자가 서버 4대에 매번 수동 설치하는 헛수고를 오래 반복했음.
- 반대로 이전에 extensionKind 없이 설치된 버전이 `~/.vscode-server/extensions/`에 좀비로 남을 수 있음 → 점검 필요.

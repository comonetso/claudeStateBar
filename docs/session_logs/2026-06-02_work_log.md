## 1. 작업 흐름 (시간순)

### 1-1. Workflow 뷰어 패널 신규 구현
**배경**: 사용자가 CLI에선 `/workflows`로 멀티 에이전트 진행을 보는데 VS Code 확장에선 안 됨. "어차피 새끼들 일하는 거 파일로 저장되니까 그걸 읽어서 현재 세션 것 뿌려주는 걸 구현할 수 없냐"고 요청.
**처리**:
- 워크플로우 5마리로 파일 구조 조사: `~/.claude/projects/<slug>/<session-uuid>/subagents/workflows/<wf_ID>/` 에 `journal.jsonl`(started/result) + `agent-<id>.jsonl`(실시간 append) + `workflows/scripts/<name>-<wfId>.js` 확인.
- [src/workflowPanel.ts](src/workflowPanel.ts) 신규 생성 — WebView 패널. settingsPanel.ts 패턴 차용.
- [src/extension.ts](src/extension.ts): `findWorkflowsForSession()`, `parseWorkflowScriptMeta()` 추가. `showSessionMenu`에 "Workflows" 항목 추가. `refreshAllSessions` 끝에서 패널 열려있으면 `pushWorkflows`로 자동 갱신.
**결과**: 컴파일 통과. 단 첫 시도에서 세션 디렉토리 경로 버그(아래 3-1).

### 1-2. 경로 파싱 버그 수정
**배경**: 패널에 워크플로우가 안 떴음. QuickPick에 Workflows 섹션 미출현.
**처리**: 세션 JSONL은 `projects/<slug>/<uuid>.jsonl`, 워크플로우는 `projects/<slug>/<uuid>/subagents/...`. `.jsonl` 확장자만 떼야 세션 디렉토리인데, `lastIndexOf('/')`로 상위 폴더를 가리켰음. `uri.path.replace(/\.jsonl$/, '')`로 수정.
**결과**: 정상 출현 확인.

### 1-3. 표시 방식 전환 — Output 채널 → WebView 팝업
**배경**: 처음엔 워크플로우 클릭 시 Output 채널에 로그 출력. 사용자 "CMD에서 보여주는 건 아닌 것 같다, 다른 로그에 묻힌다. 별도 팝업/드롭다운으로."
**처리**: WebView 패널로 전환. 자동 갱신되는 카드형 UI. 에이전트별 점(running 노랑 깜빡 / done 초록).
**결과**: 사용자 "너무너무 좋아".

### 1-4. 패널 UX 반복 개선 (사용자 피드백 다회)
- **요약 추가**: journal `result`(완료 최종 결과) + running은 `agent-<id>.jsonl` 마지막 활동(도구 호출/텍스트). `summarizeResult`, `getAgentTiming`(구 `getRunningAgentActivity`).
- **소요 시간**: agent jsonl 첫↔마지막 timestamp 차이 → `durationMs`. done은 "12.3s", running은 "경과 23s".
- **정렬**: 워크플로우 카드는 journal mtime 최신순(방금 돌린 게 위), 에이전트는 agentId 안정 정렬. (병렬 시작이라 라벨 1·2·3 순서 복원은 불가 — journal에 label 없음.)
- **에이전트 표시**: agentId → "Agent N", ✓done 개행 제거, 한 줄 head + 요약 줄.
- **한글화**: 패널 UI 라벨 전부 한글(running→진행 중, done→완료 등).
- **폰트 조절**: 맨 상단 A−/A+ 버튼. 기본 15px(+2). webview `setState` 저장. ⚠️ 영구성 한계(아래 9-1).
- **토글**: 맨 위(최신) 펼침, 나머지 제목만 접힘. 헤더 클릭 토글. `userToggled` 상태 유지.
- **삭제 버튼**: 🗑 + 확인 모달 → `wf_` 디렉토리 삭제 후 갱신.

### 1-5. 워크플로우 한국어 룰 메모리 박제
**배경**: 사용자가 패널의 에이전트 활동이 영어로 보여 못 읽음. "멀티에이전트 실행 시 어떻게 한글로?"
**처리**: 사용자 "방법2(앞으로 항상)로 박아놔" → `memory/feedback_workflow_korean.md` 생성 + MEMORY.md 인덱스 추가. 이후 워크플로우 agent() 프롬프트에 한국어 강제 한 줄 자동 삽입.
**결과**: korean-check 워크플로우로 3마리 한글 출력 검증 완료.

### 1-6. 완료 비프 오발 정밀 분석 (5마리)
**배경**: 사용자 "작업 안 끝났는데 비프 계속 울린다. 중간 결과 나오고 작업 이어지는 중에도. 화장실 갔다 헛걸음." 5마리 풀어 분석 요청.

### 1-7. 비프 수정 (구현 1 격리 + 검증 2)
**처리**: `fix-beep` 워크플로우. worktree에서 구현, 검증 2마리(정확성·회귀).
- 수정1[채택]: `getLatestTokenCount`에서 `lastAssistantEndTurnAt`를 **text 블록 있는 end_turn만** 갱신.

**결과**: 수정1·2만 메인 적용. 컴파일·빌드 통과.

### 1-8. 좀비 세션 수정 (구현 1 격리 + 검증 4)

## 3. 시행착오 / 사이드퀘스트

### 3-1. 세션 디렉토리 경로 오산
- **잘못된 가정**: sessionFile에서 `lastIndexOf('/')`로 자르면 세션 디렉토리.
- **발견**: 패널에 워크플로우 0건. 사용자 스크린샷.
- **복구**: 세션 JSONL은 `<uuid>.jsonl`, 워크플로우 디렉토리는 `<uuid>/`. `.jsonl` 확장자만 떼야 함.
- **교훈**: Claude 세션 파일과 그 서브에이전트 디렉토리는 같은 레벨에 `<uuid>.jsonl` + `<uuid>/`로 공존.

### 3-2. worktree가 vsix 패키지에 혼입
- **잘못된 가정**: worktree는 패키징과 무관.
- **발견**: vsce package 결과 51파일/268KB (정상 20/128).
- **복구**: worktree가 `.claude/worktrees/`에 생성됨 → `.vscodeignore`에 `.claude/**` 추가.
- **교훈**: 워크플로우 worktree 격리는 프로젝트 내 `.claude/worktrees/`에 생기므로 패키징·git 제외 필요.

### 3-3. 폰트/한글 오해
- **잘못된 가정**: 사용자 "개행" = 텍스트 줄바꿈 / "영어로 보임" = UI 라벨.
- **발견**: 사용자 정정 — "개행"은 ✓+done 세로 쌓임, "영어"는 에이전트 활동 원문.
- **복구**: done 아이콘 제거 + 요약 축약 원복 / UI 라벨 한글화 + 에이전트 프롬프트 한국어 지시.
- **교훈**: 모호한 피드백은 대상 확인 먼저.

## 4. 발견한 코드베이스 함정 (휘발 방지)

### 4-1. ★ thinking-only end_turn = 완료 아님 (비프 오발 핵심)
- thinking 켠 응답은 JSONL에 `[thinking]`만 든 줄 + `[text]` 든 줄로 **분리 기록**되며 **둘 다 `stop_reason:'end_turn'`**, 동일 `message.id`.
- thinking-only end_turn은 "아직 답 생성 중"인 중간 신호. 완료로 오인하면 작업 중 비프.
- 실측(60세션): thinking-only end_turn 540건(=오발원), text end_turn 994건(=진짜 완료). 빈 텍스트 0건, 역전 0건. thinking→text 간격 중앙값 8.7초, 최대 190초(settle 3초 초과 빈번).
- **대응**: `content`에 `type==='text'` 블록이 있는 end_turn만 완료로 인정.

### 4-2. 워크플로우 파일 구조
- 세션 디렉토리: `~/.claude/projects/<slug>/<session-uuid>/`
- 워크플로우: `<세션디렉토리>/subagents/workflows/<wf_ID>/journal.jsonl`(started/result, **타임스탬프 없음**) + `agent-<id>.jsonl`(실시간 append, timestamp 있음) + `agent-<id>.meta.json`(`{"agentType":"workflow-subagent"}`)
- 스크립트: `<세션디렉토리>/workflows/scripts/<name>-<wf_ID>.js`
- 에이전트 상태: journal에 started만 = running, result 있음 = done. journal `result`에 최종 출력(텍스트 또는 schema 객체).
- phase 진행은 디스크에 저장 안 됨.

### 4-3. 좀비 토스트 = dispose 버그 아닌 인스턴스 불일치
- `item.command`는 명령 ID 문자열일 뿐, 그 명령이 현재 레지스트리에 있는지 보장 안 함.
- 옛/중복 버전 인스턴스가 만든 상태바 아이템 잔존 + 그 인스턴스 비정상 종료 → 클릭 시 "command not found".
- `runCleanupOldVersions`가 실행 중 폴더를 지우면 명령 등록이 깨져 악화 → 자기 폴더 제외 가드 필수.

### 4-4. 워크플로우 worktree 위치
- 워크플로우 `isolation:'worktree'`는 `.claude/worktrees/<wf_ID>-N/`에 생성. 변경 있으면 자동 정리 안 됨 → `git worktree remove --force`로 수동 정리.

## 9. 미해결 항목

### 9-1. 즉시 처리 필요 (다음 세션 1순위) ★
- **폰트 크기 영구 저장 전환**: 현재 [src/workflowPanel.ts](src/workflowPanel.ts)는 webview `vscodeApi.setState`로 폰트(`fontPx`)를 저장하는데, **패널을 완전히 닫거나 VS Code 재시작 시 기본 15px로 리셋**됨(반쪽). 사용자가 "전역 변수로 해서 유지하는 게 맞는 방향, 내일 작업하자" 명시. → VS Code `context.globalState`(또는 configuration)에 저장하도록 전환. extension.ts에서 패널 생성 시 globalState의 fontPx를 webview로 전달, A−/A+ 변경 시 webview→extension 메시지로 globalState 갱신.

### 9-2. 검증 미완
- 비프 수정1·2, 좀비 수정 ①~④ 모두 **실기기·사용자 검증 미완**. 재설치(claude-context-bar-1.7.7.vsix) + 창 다시 로드 후 (1)thinking 끝마다 울리던 비프가 멎는지 (2)좀비 토스트 시 팔레트 "유령/오래된 상태바 항목 정리" 동작하는지 확인 필요.

### 9-3. 별도 트랙
- 좀비 수정의 Remote-SSH 한계: `extensionUri.scheme !== 'file'`일 때 `currentExtDir`이 비-file 경로라 `isProtected` 무력화 가능(단 원격 폴더는 애초 삭제 후보 아니라 안전상 무해, 검증에서 비차단 관찰로 분류).
- 비프 수정3(mtime 재확인) 폐기했으나, settle 윈도우 밖 늦은 활동 포착 안전망은 여전히 부재. 수정1로 대부분 해결되나 추후 필요 시 "재파싱한 마지막 의미있는 timestamp 비교"로 재설계 가능.

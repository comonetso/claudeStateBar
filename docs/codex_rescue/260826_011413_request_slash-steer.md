# 슬래시 명령 경로 확인

가벼운 배관 확인이다. **탐색 금지. 파일 읽기 금지.** 아래만 하고 끝내라.

1. 이 명령을 실행하고 끝날 때까지 기다려라 (약 40초, 정상이다):

   node -e "setTimeout(function(){console.log('OK')}, 40000)"

2. 끝나면 **한 줄로만** 답해라. 받은 토큰들을 나열하면 된다.

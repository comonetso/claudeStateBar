# 실행 중 끼어들기 시연

이것은 배관 시연이다. 아래를 순서대로 그대로 따라라. 질문하지 마라.

1. 이 단어를 기억해라: DEMO-BASE
2. 아래 명령을 현재 디렉토리에서 실행하고 끝날 때까지 기다려라.
   약 40초 걸린다. 정상이며 반드시 필요하다. 줄이거나 건너뛰지 마라.

   node -e "setTimeout(function(){console.log('DONE')}, 40000)"

3. 그 명령이 끝난 뒤에만 짧은 최종 메시지 하나로 답해라.
   1번 단어를 그대로 포함해라.
